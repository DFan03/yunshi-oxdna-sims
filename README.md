# yunshi-oxdna-sims

Scripts (no data) for two oxDNA/oxRNA coarse-grained simulation projects: RNA kissing-loop designs (2H, K1, T3, IVT variants; monomer and 8mer) and DNA nanotweezers / T3IVT with umbrella sampling.

Full README, computing-logic docs (`docs/SCRIPTS.md`) and setup are being added; this is the first commit (scaffold + collected scripts).
